# SampleMale prototype sprite set

This runtime sprite set is a curated, unmodified selection from the locally
provided `Assets/SampleMale/` source library.

Included animations:

- `Unarmed Idle`: 8 directions, 5 frames per direction
- `Walking`: 8 directions, 8 frames per direction
- `Unarmed Attack 1`: 8 directions, 5 frames per direction

The prototype constructs Godot `SpriteFrames` at runtime from these individual
transparent PNG frames. The complete 2,512-frame source library remains local
and is excluded from Godot's import scan.
